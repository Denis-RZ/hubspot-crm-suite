Appendix

HubSpot API reference used by the sandbox

HubSpot API 参考

REF

CRUD objects

List, create, update, and delete CRM records for deals, contacts, and companies.

GET /crm/v3/objects/{type} POST /crm/v3/objects/{type} PATCH /crm/v3/objects/{type}/{id} DELETE /crm/v3/objects/{type}/{id}

Search and filters

Deal search powers name, stage, and pipeline filtering without loading fake local data.

POST /crm/v3/objects/deals/search

Metadata

Form dropdowns use real HubSpot metadata, so the user cannot submit invalid options.

GET /crm/v3/pipelines/deals GET /crm/v3/properties/companies/industry

Associations

Deal links are separate association records. Type IDs are fixed HubSpot constants.

GET /crm/v3/objects/deals/{id}/associations/{type} PUT /crm/v3/objects/deals/{id}/associations/{type}/{targetId}/{typeId}

type 3 = contact; type 5 = company.

Auth:Private app token in Authorization: Bearer header. Base URL: https://api.hubapi.com/
