What it demonstrates

Built from scratch, no shortcuts從零打造，沒有走捷徑

Every feature here is code the author owns end to end — no third-party CRM behind the curtain.這裡的每個功能都是作者從頭到尾自己寫的程式碼——背後沒有任何第三方 CRM。

🔗

Self-built data layer自建資料層

Records, pipelines, stages, lifecycle stages, and industry options all come from code the author wrote — nothing is a mock, nothing depends on a third party.

交易資料、銷售流程、階段、生命週期階段與產業選項全部來自作者自己寫的程式碼——沒有模擬資料，不依賴任何第三方。

🔄

Correct association model正確的關聯模型

Deals, contacts, and companies are separate objects. Relationships are explicit, bidirectional links — not embedded fields.

交易、聯絡人與公司是各自獨立的物件。關聯以明確的雙向連結建立，而非內嵌欄位。

▶

Inline expand rows列內展開

Click ▶ on any deal, contact, or company row to see linked records inline. No separate screen, no navigation away from the table.

點擊任一列的 ▶ 即可在原地查看關聯資料，不需切換畫面或離開表格。

📦

Runtime plugin system執行期外掛系統

Upload a ZIP with a .plugin.dll and a .js module. A new panel appears in the workspace immediately — without touching the core codebase.

上傳包含 .plugin.dll 與 .js 模組的 ZIP 檔，新面板會立即出現在工作區——不需修改核心程式碼。

🏭

Different-domain module跨領域模組

A manufacturing defect-tracking module (Defects / QA) runs on the same module contract as the CRM panels, with its own storage, and optionally cross-links to a Company record.

製造瑕疵追蹤模組（Defects / QA）採用與 CRM 面板相同的模組介面，擁有自己的資料儲存，並可選擇性地連結到 Company 紀錄。

⚠️

Field-level error handling欄位層級錯誤處理

When a write is rejected, the error is parsed once and shown on the exact field — not just a generic toast message.

當寫入被拒絕時，錯誤只會被解析一次，並顯示在正確的欄位上——不只是籠統的提示訊息。

The app

Three panels, one sandbox三個面板，一個沙盒

Deals, Contacts, and Companies each have their own table, filters, pagination, inline edit, and expand row.交易、聯絡人與公司各自擁有獨立的表格、篩選、分頁、行內編輯與展開功能。

All data shown is generated by the app itself and persists to a local file — no external account involved.畫面中顯示的資料皆由應用程式自行產生，並儲存於本機檔案——不涉及任何外部帳號。

Workflow

The right order matters in CRMCRM 中，正確的順序很重要

The app enforces the same hierarchy a real CRM would.此應用程式遵循與真實 CRM 相同的層級架構。

1

Create company建立公司

Industry options come from a fixed set of values. The field only accepts valid values — no free text.

產業選項來自固定清單，欄位只接受有效值，不可自由輸入文字。

2

Create contact建立聯絡人

Email is the unique key. Duplicates are rejected and the UI maps the error to the exact field.

Email 是唯一識別鍵。重複資料會被拒絕，畫面會將錯誤對應到正確欄位。

3

Create deal建立交易

Switch pipeline — stages reload instantly. Wrong stage for that pipeline? Rejected, same as a real system.

切換銷售流程時，階段會立即重新載入。階段與流程不符？會被拒絕，就像真實系統一樣。

4

Associate & cross-link建立關聯與跨模組連結

Link from the ⋯ row menu. Expand ▶ to verify the link. The Defects module can point at a Company the same way.

從列選單的 ⋯ 建立關聯，展開 ▶ 可驗證關聯是否成立。Defects 模組也能以同樣方式連結到 Company。

Tech stack

Simple stack, self-built end to end簡單的架構，從頭到尾自己打造

No ORM, no bundler, no framework overhead, no external service — just the right tools for the job.沒有 ORM、沒有打包工具、沒有框架負擔、沒有外部服務——只用最適合的工具完成任務。

Backend後端

C# · ASP.NET

Minimal API host. Each module registers its own routes. LocalCrmStore persists everything to one JSON file.

Minimal API 架構。每個模組註冊自己的路由。LocalCrmStore 將所有資料儲存在單一 JSON 檔案中。

Frontend前端

Native ES modules

No React, no Vue, no bundler. Each panel is one JS module with renderPanel(), renderNav(), and mount().

沒有 React、沒有 Vue、沒有打包工具。每個面板都是一個獨立的 JS 模組，包含 renderPanel()、renderNav() 與 mount()。

Data layer資料層

LocalCrmStore

File-backed store. Full CRUD for deals, contacts, companies, defects. Associations tracked as simple bidirectional links — no tokens, no network calls.

以檔案為基礎的儲存層，完整支援交易、聯絡人、公司、瑕疵紀錄的 CRUD。關聯以簡單的雙向連結追蹤——不需金鑰，不需網路呼叫。

Plugins外掛

Runtime loading

ZIP upload → DLL + JS module registered at runtime. Actions dispatched through the host. No restart needed.

上傳 ZIP → 執行期註冊 DLL 與 JS 模組。動作透過 host 分派，不需重新啟動。

Get started

Clone it and run — nothing to configure複製後直接執行——不需任何設定

No account, no token, no signup. Run one command, open localhost:5100.不需帳號、不需金鑰、不需註冊。執行一行指令，打開 localhost:5100。
