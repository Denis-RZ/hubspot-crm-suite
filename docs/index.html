What it demonstrates

Built around real HubSpot behavior

Every feature in this sandbox mirrors how production HubSpot integrations work.

🔗

Live HubSpot integration

Records, pipelines, stages, lifecycle stages, and company industry options are all read directly from HubSpot — nothing is hardcoded.

🔄

Correct association model

Deals, contacts, and companies are separate objects. Relationships are created through the HubSpot association API — not as embedded fields.

▶

Inline expand rows

Click ▶ on any deal, contact, or company row to see linked records inline. No separate screen, no navigation away from the table.

📦

Runtime plugin system

Upload a ZIP with a .plugin.dll and a .js module. A new panel appears in the workspace immediately — without touching the core codebase.

📋

CSV import with preview

Export records, edit the CSV, run validation row by row, then apply. Every row is checked against HubSpot rules before a single write happens.

⚠️

Field-level error handling

When HubSpot rejects a value, the error is parsed once and shown on the exact field — not just a generic toast message.

The app

Three panels, one sandbox

Deals, Contacts, and Companies each have their own table, filters, pagination, inline edit, and expand row.

All data shown is live from a HubSpot sandbox account.

Workflow

The right order matters in CRM

The sandbox enforces the same hierarchy as a real HubSpot account.

1

Create company

Industry options are loaded from HubSpot. The field only accepts valid values — no free text.

2

Create contact

Email is the unique key. HubSpot rejects duplicates and the UI maps the error to the exact field.

3

Create deal

Switch pipeline — stages reload instantly from HubSpot. Wrong stage for that pipeline? The API says no.

4

Associate & audit

Link from the ⋯ row menu. Expand ▶ to verify the link. The Audit plugin scores data quality.

Tech stack

Simple stack, real integration

No ORM, no bundler, no framework overhead — just the right tools for the job.

Backend

C# · ASP.NET

Minimal API host. Each module registers its own routes. HubSpotDealsClient wraps all API calls with a plain HttpClient.

Frontend

Native ES modules

No React, no Vue, no bundler. Each panel is one JS module with renderPanel(), renderNav(), and mount().

Integration

HubSpot API v3

Private app token. Full CRUD for deals, contacts, companies. Separate association endpoints with fixed type IDs.

Plugins

Runtime loading

ZIP upload → DLL + JS module registered at runtime. Actions dispatched through the host. No restart needed.

Get started

Run it against your own HubSpot sandbox

Set your private app token, run one command, open localhost:5100.
