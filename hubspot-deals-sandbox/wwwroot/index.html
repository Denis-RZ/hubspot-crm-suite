How associations work

In HubSpot, deals don't contain contact or company data — they reference them through separate association records. This panel sends a PUT request to create the link and a GET to read it back.

Association type IDs HubSpot uses fixed numeric IDs per object pair: deal→contact = 3, deal→company = 5.
Why dropdowns instead of text inputs Associations fail silently if you reference an ID that doesn't exist. Dropdowns eliminate that class of error entirely.
